## 结构与位移

所有图均为同一单定子的局部展开截面：初级一个铁齿和一块永磁体；次级两个铁齿和一块永磁体。两侧线圈截面属于同一个集中绕组。两个永磁体均为 N 在上、S 在下，同向充磁。

位移原点按用户要求定义，未沿用论文的 x=0 原点；因此图的排序不同于论文图2。

1. **永磁体完全对齐（s=0）**：借鉴论文图2c。相对永磁体的磁势构成局部串联励磁，在磁体与相邻铁齿之间形成漏磁回路；示出的主磁通返回分量在对齐铁齿区域向下。
2. **重叠一半（s=w/2）**：借鉴论文的部分对齐状态。重叠区域保留局部串联漏磁回路；未重叠的磁体—铁齿区域示出向上的有效主磁通分量，对齐铁齿区域示出向下的返回分量。
3. **初级永磁体与次级铁齿对齐（s=w）**：借鉴论文图2a。两个永磁体经各自对应的铁齿向绕组侧提供向上的主磁通，边缘仍可能存在局部漏磁。

## 主磁通和漏磁通的表示

主磁通用带方向箭头的长虚线及端部 ⊙/⊗ 表示。⊙ 表示出纸面，⊗ 表示入纸面；它们表示三维磁通回路的截面外连接，不表示另加一个定子，也不是绕组电流标记。回路在同一个单定子的相邻周向磁路单元内闭合。

漏磁通用绕组下方的局部闭合虚线表示，磁体内上行、相邻铁齿或边缘空间返回。图中永磁体内的白色上箭头表示充磁方向。

这是磁路分量的定性示意，不是三维有限元求解后的合成 B 磁力线图。代表线条的数量和粗细不表示磁通大小；不能据此认定半重叠处净磁链为零，也不能据此计算推力。实际端部效应、饱和和各分量比例需有限元验证。

## 字体规范

中文标签采用 Noto Serif CJK SC 正体，拉丁和希腊物理量采用 Times New Roman 斜体；s、w、g、Φ 和 σ 斜体。N/S 极性字母、数字和描述性下标 m 使用正体。原生 draw.io 模型采用 fontStyle=2 或内嵌 HTML i 标签实现变量斜体，PNG 直接由该模型渲染。

用户点名的“drawio 字体变量斜体”和“科研绘图”两个 skill 未安装或未在当前环境发现，本版没有声称调用它们，而是按用户明确要求落实以上制图规范。

## 校核记录

永磁体重叠比例为 100%、50%、0%；第三幅中初级永磁体与次级左铁齿准确对应。各图只有一个初级铁芯、一个次级铁芯和两块永磁体。箭头坐标方向、⊙/⊗ 的圆形符号以及浏览器中的字体样式已经检查；高清 PNG 在添加 dpi 元数据前后像素完全一致。
