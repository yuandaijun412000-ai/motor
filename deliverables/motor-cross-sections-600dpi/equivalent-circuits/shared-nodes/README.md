# 二维等效磁路：共用节点连接版

`motor_four_source_shared_nodes.drawio` 包含两页：四源三维图、四源二维共用节点图。`planar_shared_nodes.png` 为8000 × 9900像素、600 dpi二维高清图，另提供同名 SVG。

## 本次核对与修改

依据此前四源版的真实节点关系，检查所有重复节点引用。原图已有16个不同磁路节点，没有同名节点被画为两个不同节点的情况，因此未减少独立节点数。

此前24条磁路支路的端点采用独立坐标绘制，本次将其48个端点统一绑定到16个原生 draw.io 节点对象。每个节点仅保留一个连接点，汇入该节点的三条支路均引用同一个对象。在 draw.io 移动节点时，相连的黑色支路随节点保持连接；元件图形和用于说明磁通的彩色箭头仍可分别编辑。

省略磁阻符号的支路仍具有原磁路含义，跨过这些支路不能仅因图上没有 R 符号而认定磁位相同。按此前用户确认，本次保持“只删符号、保留连线和漏磁回路”的要求，未将省略磁阻设为零。若另行作零磁阻理想化，应作为新的模型重新推导；该操作与重复节点去重不同。

四个永磁体磁势源（初级两个、次级两个）、永磁体磁阻、工作气隙磁阻、两个主回路、三个漏磁回路和极性保持一致。三维页保留原图。变量 F、R 斜体，说明性下标和节点编号正体。

## 校核

已验证16个唯一节点、24条磁路支路、48个共享端点引用，且每个节点均有三条实际相连支路；在 mxGraph 中实际移动 A0，验证其三条支路端点同时随动，再恢复原位置。已检查四源、五条选示闭合路径及变量斜体，PNG 分辨率元数据修改前后像素一致。详情见 `node_connectivity_validation.json`。

节点数仍为16，是核对后没有重复独立节点可进一步缩并的结果；本版改进的是相同节点在可编辑文件中的共用连接关系。数值磁位相等性尚未由磁路求解或有限元场证明。
