# 四永磁体／四磁势源等效磁路修正版

本版替代此前未经等效验证而合并为两个磁势源的版本。按完整单元保留初级两个、次级两个永磁体的四条独立励磁支路；同类磁体参数可以相等，但不能据此合并连接节点。

## 文件

- `motor_four_source_circuits.drawio`：可在 diagrams.net 打开的两页原生矢量文件；第1页为三维，第2页为二维展开。线条、箭头、元件和标签均可编辑。
- `four_source_circuit_3d.png`：8500 × 8050 像素，600 dpi。

- `four_source_topology.json`、`validation_report.json`、`font_validation.json`：节点、支路、回路映射和校验结果。

## 对照论文与用户要求

参考罗俊等《双交替极横向磁通直线电机的基础研究》图3、图4和第2.1节。三维与二维图使用同一套16节点、24支路网络，独立网孔数为9；图中选示2个主磁通回路和3个漏磁回路，并非声称整个网络仅有5个独立网孔。

四个永磁体磁势源分别为 F_pri,1、F_pri,2、F_sec,1、F_sec,2。四条支路的永磁体磁阻分别为 R_pM,1、R_pM,2、R_sM,1、R_sM,2。图中的这些 R 标签表示对应整条支路的等效磁阻；论文中的串联系数归入其定义，不能将磁阻系数直接解释为永磁体数量。

按用户确认，仅删除 Rt、Rst、Rgl、Rpy、Rsy、Rtσ、Rstσ 的元件符号和名称，保留对应连线及三个漏磁回路。未显示磁阻符号不表示该支路磁阻为零；此图用于结构与路径说明，不可将删去符号后的连线直接当成理想零磁阻去求解。

红色实线为初级源1对应的主回路1，蓝色实线为次级源1对应的主回路2。红色虚线表示初级源1的局部漏磁回路1；蓝色虚线表示次级源1的局部漏磁回路2；绿色虚线表示初级源2与次级源2共同参与的漏磁回路3。各闭合路径均经过相应励磁支路，箭头按论文图示位置给出参考方向。

三维图中四个源的正极均在空间支路上端；二维展开后后排源的图面方向随节点展开变化。这是同一网络的坐标映射，未改变物理充磁方向。黑点为连接节点，交叉无黑点处不连接。灰色虚框表示绕组交链区域；图示为空载永磁励磁，电枢反应磁势取零。

保留单定子设置。本图以论文完整单元的四源支路拓扑为依据，未将完整单元的三维永磁体数量与单一局部截面中的可见数量混同。具体尺寸、磁阻值及不同运动位置的数值磁通需要电机几何和材料参数进一步确定；本交付不包含有限元求解。

变量 F、R 及坐标 u、r、z 为斜体，说明性下标与节点编号为正体。已校验两页四源数量、源极性、三维与二维对应关系、闭合路径、箭头、引线落点和实际渲染的变量斜体。PNG 从同一原生 draw.io 模型渲染。
